## ১. ফোল্ডার কাঠামো (Folder Structure)

├── sql/
│   ├── .htaccess              # সরাসরি অ্যাক্সেস ব্লক
│   └── database.sql           # সম্পূর্ণ MySQL স্কিমা ও বাংলা সিড ডেটা
├── lang/
│   ├── .htaccess              # সরাসরি অ্যাক্সেস ব্লক
│   └── bn.php                 # সমস্ত বাংলা লেখা (এক জায়গা থেকে এডিটযোগ্য)

│   ├── .htaccess              # সরাসরি অ্যাক্সেস ব্লক

## ২. cPanel-এ ধাপে ধাপে ইনস্টলেশন গাইড

### ধাপ ১: সাবডোমেইন তৈরি করুন (যেমন: `checklist.yourdomain.com`)
1. আপনার **cPanel**-এ লগইন করুন।
2. **Domains** → **Create A New Domain** অপশনে যান।
3. Domain ঘরে লিখুন: `checklist.yourdomain.com`।
4. *"Share document root"* আনচেক রাখুন যাতে আলাদা ফোল্ডার তৈরি হয় (যেমন: `checklist.yourdomain.com`)।
5. **Submit** ক্লিক করুন।

### ধাপ ২: SSL (HTTPS) চালু করুন
1. cPanel-এ **SSL/TLS Status** (অথবা **Let's Encrypt SSL**) অপশনে যান।
2. `checklist.yourdomain.com` সিলেক্ট করে **Run AutoSSL** ক্লিক করুন।
3. ১–২ মিনিটের মধ্যে HTTPS (সবুজ তালা চিহ্ন) চালু হয়ে যাবে। নিরাপদ কুকির জন্য HTTPS ব্যবহার করা জরুরি।

### ধাপ ৩: MySQL ডেটাবেস ও ইউজার তৈরি করুন
1. cPanel-এ **Manage My Databases** (অথবা **MySQL Databases**) অপশনে যান।
2. **Create New Database** ঘরে নাম দিন (যেমন: `hotel_checklist`) → **Create Database**।
   *(সম্পূর্ণ নাম হবে `cpaneluser_hotel_checklist` — এটি নোট করে রাখুন)*।
3. নিচে **Add New User**-এ ইউজারনেম ও একটি শক্তিশালী পাসওয়ার্ড দিন → **Create User**।
4. **Add User To Database** অংশে আপনার ইউজার ও ডেটাবেস সিলেক্ট করে **Add** ক্লিক করুন।
5. পরের পেজে **ALL PRIVILEGES** টিক দিন এবং **Make Changes** ক্লিক করুন।

### ধাপ ৪: File Manager দিয়ে ফাইল আপলোড করুন
1. cPanel → **File Manager** খুলুন এবং আপনার সাবডোমেইনের ফোল্ডারে (`checklist.yourdomain.com`) যান।
2. উপরের **Upload** বাটনে ক্লিক করে এই `.zip` ফাইলটি আপলোড করুন।
3. আপলোড শেষে `.zip` ফাইলে রাইট-ক্লিক → **Extract** করুন।
4. নিশ্চিত করুন `index.php`, `.htaccess`, `install.php`, `app/`, `config/`, `sql/`, `lang/`, `assets/` সরাসরি সাবডোমেইনের রুট ফোল্ডারে আছে (কোনো অতিরিক্ত সাবফোল্ডারের ভেতরে থাকলে সব ফাইল মুভ করে রুটে আনুন)।
5. cPanel → **MultiPHP Manager** থেকে এই ডোমেইনের PHP ভার্সন **PHP 8.1 / 8.2 / 8.3** সেট করুন।

### ধাপ ৫: `install.php` রান করুন ও লক/ডিলিট করুন
1. ব্রাউজারে যান: `https://checklist.yourdomain.com/install.php`
2. ধাপ ৩-এ তৈরি করা ডেটাবেস নাম, ইউজারনেম, পাসওয়ার্ড এবং মালিকের (Owner) নাম, ইমেইল ও পাসওয়ার্ড দিন।
3. **ইনস্টল করুন** বাটনে ক্লিক করুন। এটি স্বয়ংক্রিয়ভাবে:
   - `sql/database.sql` ইমপোর্ট করে সব টেবিল ও বাংলা সিড ডেটা তৈরি করবে।
   - মালিকের অ্যাকাউন্ট তৈরি করবে।
   - `config/config.php` তৈরি করবে এবং `install.lock` তৈরি করে ইনস্টলার লক করে দেবে।
4. **গুরুত্বপূর্ণ:** ইনস্টলেশন শেষে নিরাপত্তার জন্য cPanel File Manager থেকে `install.php` ফাইলটি **Delete** করে দিন।

## ৩. অ্যাডমিন প্যানেল থেকে নতুন কিছু যোগ করার নিয়ম

মালিক (Owner) বা ম্যানেজার (Manager) হিসেবে লগইন করে উপরের/নিচের **সেটিংস** মেনুতে যান:

1. **নতুন রুম বা ফ্লোর যোগ করা:** `ফ্লোর ও রুম` ট্যাবে গিয়ে ফ্লোর সিলেক্ট করুন, রুম নম্বর (যেমন `406`) লিখুন এবং **নতুন যোগ করুন** চাপুন। ↑ / ↓ বাটন দিয়ে ক্রম পরিবর্তন করা যাবে।
2. **নতুন সেকশন যোগ করা:** `সেকশন` ট্যাবে সেকশনের নাম দিন। সেকশনটি চেকআউট সম্পূর্ণ হওয়ার শর্তে গণ্য করতে চাইলে **"চেকআউট সম্পূর্ণ হওয়ার জন্য গণ্য হবে"** বক্সে টিক দিন।
3. **নতুন অপশন/আইটেম যোগ করা:** `অপশন / আইটেম` ট্যাবে সেকশন বেছে নিন, নাম লিখুন, ধরন (`চেকবক্স` বা `কাউন্টার`) ও সর্বোচ্চ সংখ্যা দিন। নির্দিষ্ট কিছু রুমে দেখাতে চাইলে **"নির্বাচিত রুম"** বেছে নিয়ে সেই রুমগুলোতে টিক দিন (যেমন: এসি রিমোট)।
4. **নতুন এক্সট্রা আইটেম যোগ করা:** `এক্সট্রা তালিকা` ট্যাবে আইটেমের নাম ও সর্বোচ্চ সংখ্যা দিয়ে **নতুন যোগ করুন** চাপুন।
5. **রুম ডিফল্ট সেট করা:** `রুম ডিফল্ট` ট্যাবে রুম বেছে নিয়ে কোন আইটেম কয়টি থাকবে তা সেট করুন। পরিবর্তন আজকের তারিখ থেকে কার্যকর হবে এবং পুরানো তারিখের হিসাব অক্ষুণ্ণ থাকবে। চাইলে এক ক্লিকে **"এই রুমের ডিফল্ট সব রুমে কপি করুন"** ব্যবহার করতে পারেন।
6. **স্টাফ অ্যাকাউন্ট তৈরি (শুধু মালিক):** `ব্যবহারকারী` ট্যাবে নাম, ইমেইল, পাসওয়ার্ড ও ভূমিকা (`Staff` বা `Manager`) দিয়ে তৈরি করুন। এখান থেকেই অ্যাকাউন্ট নিষ্ক্রিয় বা পাসওয়ার্ড রিসেট করা যাবে।

## ৫. ব্যাকআপ পরামর্শ (phpMyAdmin Export)

সপ্তাহে অন্তত একবার ডেটাবেস ব্যাকআপ নিন:
1. cPanel → **phpMyAdmin** খুলুন।
2. বাম দিক থেকে আপনার ডেটাবেস (`cpaneluser_hotel_checklist`) সিলেক্ট করুন।
3. উপরের **Export** ট্যাবে ক্লিক করুন।
4. Format হিসেবে **SQL** রেখে **Export / Go** বাটনে ক্লিক করুন — `.sql` ফাইলটি আপনার কম্পিউটার বা Google Drive-এ সংরক্ষণ করে রাখুন।
